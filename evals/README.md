# M0 评测材料与运行

`datasets/learning.v1.json` 固定 24 个学习场景，开发集 16、保留集 8；`resources.v1.json` 固定 12 个资源任务，开发集 8、保留集 4。按任务家族划分，同一主题的用途变体留在同一集合。`unfold check` 检查家族交叉、完全重复及文本近似，并输出待人工复核的相似对；文本规则不能证明没有语义泄漏。

资源任务覆盖复用、定制制作、构建修复、边界操作、图片来源与不支持的能力。它们定义 M4/M5 的验收任务，M0 不执行生成代码或宣称资源技术成功。

## 离线检查

```sh
uv sync --locked
uv run unfold check
uv run unfold export-schemas --check
uv run unfold verify-evidence
uv run pytest -q
uv run ruff check src scripts tests
uv run ruff format --check src scripts tests
uv run mypy src
```

源数据是人工编写的固定输入；成功例是协议例，不是期望模型逐字复制的唯一答案。允许合理结构、标题与层次数量差异。核心宽场景检查至少三层有用探索，窄场景检查及时根叶子；其余场景不以层数判质量。

## 真实实验

本节 M0 基线使用明确的 `baseline` 命令执行付费调用；应用的 `deepseek` worker 和标为 live/public_eval 的实验脚本也会付费，不属于普通 CI。创建 `.env.local`，参考根目录 `.env.example`，配置供应商凭据、模型、币种、价格与费用上限；现有进程环境优先，文件内容不执行 shell 表达式。

```sh
uv run unfold baseline --env-file .env.local \
  --scenario backend-1 --scenario midpoint-1 --repetitions 3 --probes
```

`--probes` 增加八个阶段的真实契约调用和三个小型兼容性探针：正向 schema、与 schema 冲突的提示、故意截断。故意失败独立统计，不加入正常学习成功率。M0 CLI 拒绝保留集场景；后续冻结后评估需新增独立命令，不用此入口调参。

每个批次保存选择与次数（调用前）、模型/参数/版本、完整请求与可见输出、实际用量、修复/失败、任务结果、延迟和源码快照。调用逐行追加，已失败试验不删除。`runs/` 默认忽略入库，包含供应商响应 ID 和本地轨迹；公开报告只复制经过检查的必要证据，不能复制 `.env.local` 或 HTTP Authorization。

费用使用返回用量的保守高峰预估，不宣称是实际扣费；实际账单或余额差另记。跨批次调用必须扣除此前已支出的保守费用，每个新批次不能把已消费的授权预算清零。普通 CI 与 pytest 不需要模型密钥、不调用真实模型、不读取模型私密配置；浏览器测试访问本地 HTTP。

公开证据中的本机路径经过脱敏，原件保留在忽略的本地目录；脱敏前后哈希与清单更新见 `evidence/publication-redactions.json` 和 [开源整理记录](../docs/reports/open-source-publication-2026-10-07.md)。此处理只改变路径表示，不改变实验结果或模型输出。

## 评分口径

| 维度 | 0 不满足 | 1 部分满足 | 2 满足 |
| --- | --- | --- | --- |
| 用途适配 | 忽略或改变用户用途 | 只有措辞/轻微侧重变化 | 分支、解释、例子与目标相符 |
| 增量深度 | 同义改写/无意义细分 | 少量新增但重复明显 | 增加服务目标的知识或机制 |
| 结构与范围 | 职责混乱、明显缺口或越界 | 局部重叠/边界不清 | 划分依据明确、职责与排除范围一致 |
| 停止合理性 | 过早停止或狭窄范围硬拆 | 理由不充分 | 下一层价值/叶子理由与当前目标相符 |
| 内容/题目对齐 | 超出已讲内容或错误解析 | 对齐部分不足/表述歧义 | 考点、答案、解析引用对应已提供版本 |

事实、关系与官方标准的待核验项另列 `unverified`；发现明确错误记录依据，不用结构合法替代事实正确。阅卷者记录身份与依据；Codex 审阅标为 `agent_review`，不能记作独立人工评测。保留集评分标准从开发结果确定后冻结，不根据保留结果回调阈值。

报告分别给出首次结构合法（每阶段首次调用为分母）、全部正常调用格式合法、有限修复后领域合法、学习任务成功（完整发起的链路为分母）、阶段探针成功和故意兼容性失败。成本包括全部失败/修复/探针，费用未知时每成功任务成本不可计算；小样本 P50/P95 使用最近秩，不用于承诺线上性能。
