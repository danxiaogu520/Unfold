# M6 上下文策略技术验收

日期：2026-10-07。M6-01～M6-06 的工程实现、保留集候选对照和离线回放完成；独立人审与事实准确率未知。采用当前路径默认值，不宣称结构策略已经提高教学质量。

## 实现与范围

学习动作可显式选择 current_path、structural_relevance、all_history；默认请求保持历史幂等兼容，非默认策略使用不同活动身份。界面“本次参考范围”同时适用于讲解、展开、重评与练习。真实 PostgreSQL 测试确认不同策略不会复用错误的活动材料，过期结果不能覆盖已发布内容。

必需输入、完整目标/设定/范围/路径及已有子项先保留，再选择正文。输入材料预算 24,000 UTF-8 字节，预留 4,000 输出 token；供应商请求中的指令/schema 另受 48,000 字节检查。这些是应用执行限制，不是供应商上下文窗口的声明。全历史超限返回明确的 HTTP 413，事务回滚，不生成新任务或叶子；用户可显式改选策略。

全历史包含快照提供的全部正文修订、学习设定修订与关系；不包含供应商日志、媒体文件或不存在于快照中的资料。当前路径选当前活动正文；结构策略加入保存关系与关键词候选，记录分数、选取、省略与原因。该排序不校验关系的知识语义。

较远正文使用最多 600 字符的程序摘录，明确注明省略字符数、源内容、源设定与 fact_status。ContentSummary 持久缓存绑定内容/节点、设定、结构、路径、父节点及问题标记的 SHA；不是新的 LLM 摘要，也没有事实认证。修改设定和发布新正文的真实数据库回归均使旧缓存失效；旧记录保留。依据见 [决策 0004](../decisions/0004-context-strategies.md)。

## 固定数据与协议

使用 M0 未用于调提示的 8 个学习保留场景：circuits、perspective、phonemes、seasons 各两个。每个场景有 10 / 120 / 600 节点的公开合成快照，总计 24 份；每节点一个正文版本、每快照一条明确跨分支关系。以 circuits-1 为例，正文分别 1,858 / 21,108 / 105,108 字符，其他场景的实际规模记录在各快照中。

本轮全部规模内容和设定来自标记的固定替身/合成材料，不混入既有私人学习空间或 M2 真实正文。冻结快照、代码、app-prompt.v3、质量口径和随机顺序后才推理；每个单元一次，8 场景 × 3 规模 × 3 策略 = 72 单元。没有根据保留集修改提示或评分；实际模型别名 deepseek-flash，temperature=0.2、reasoning=none，别名无法锁定供应商快照。

推理批次源码保留调用前版本；最终工程快照另外包含 HTTP 超预算错误映射、回归和指标汇总补充，未修改提示或选择算法。两份快照分别保留，不能把最终源码 SHA 冒充首次调用时版本。

调用使用真实持久 run、lease heartbeat、预算预留与结算。在取得有效候选后，程序主动取消，阻止正式发布，保证三种策略面对同一正式节点/设定/版本。**56 个有效候选均保留 cancelled 终态，正式发布 0 个**；候选合法不能写成产品任务成功率。正常发布、取消竞争与 UI 使用由单独确定性测试验证。

质量口径在调用前冻结：契约与引用、完全重复文本块、违反纯文字要求的资源、领域词覆盖代理指标。词覆盖不等于用途适配、遗漏检查或事实准确率，未与独立人工评分校准。不同规模下当前路径实际输入相同，三次模型输出仍有随机波动；不能把 24 个单元称为 24 个独立领域任务。选择时间包含本次材料构建、登记、推理/修复、主动取消和轨迹读取；不包含创建合成空间、人工审阅或正式发布。

## 复用、遗漏和关系检查

代码代理编写的五个固定回归样例见 [context-review.v1.json](../../evals/datasets/context-review.v1.json)：同名异义保留不同身份；同范围明确引用允许不同路径标题；较窄子项误引较宽父概念必须修复；明确 related 端点的选取与路径省略有日志；严格前置循环拒绝而普通关系循环允许。原文/设定/路径依赖变化与超预算也有回归。

这些检查证明程序遵循声明与引用规则，不证明所有关系语义正确；没有凭标题相似自动合并。全历史也可能把过期或问题正文带入输入，源状态有标签但模型仍可能误用。独立人工检查用途适配、实质重复/遗漏、事实与关系仍未执行。

## 验证与采用决定

**204 项 Python 测试（真实 PostgreSQL，0 跳过）、8 项 Chromium 浏览器流程、13 项统一检查通过**。针对性 HTTP/缓存回归 23 项通过；类型/格式/schema 检查通过，M0～M5 冻结证据回放未改变。新增源码/指标汇总与证据校验另通过格式和离线验证。远程 CI 未执行。

保留当前路径默认值。结构选择作为显式关联需求选项；全历史只适合装得下的小快照。没有独立质量收益证据，不引入向量、重排、模型摘要或路由。

离线复核：运行 `.venv/bin/python scripts/verify_context_evidence.py`。原始比较保存在 evals/evidence/m6-context/heldout-v1；`scripts/summarize_context.py` 可从 report.json 重算 derived-metrics.json，不访问模型。重新真实实验必须使用新目录与预算，不覆盖保留集历史结果。

限制：规模正文为合成填充；本轮是解释候选对照，没有大空间数据库查询延迟/内存基准，没有其他操作的保留集对照；关键词质量未校准，程序摘录可能省掉旁支后段；样本一次、模型别名不锁快照、事实与独立人审未知。Mermaid 大型惰性 bundle 警告与 Starlette TestClient 依赖弃用提示仍保留；不影响本次通过结论，但不声称不存在后续维护工作。
