# 网页资源执行边界

日期：2026-10-07。M5 技术验证完成。

自定义资源代码在独立、临时的 Chromium 进程运行，保留 Chromium 自身沙箱；预览来源为 opaque `null`，没有学习应用窗口、Cookie 或 localStorage。模型凭据和后端配置不传入驱动环境。主应用只接收 PNG 画面，坐标、有限按键和文本经过后端校验后进入演示；模型脚本不在主应用 DOM 中执行。

执行叠加静态能力拒绝、CSP、全部请求拦截、拒绝 HTTP/CONNECT 代理以及禁止非代理 WebRTC UDP；文件、导入、worker、外部资源和明显无界循环不提供。每次操作受墙钟超时限制，超时终止该进程组；用户可以停止、重置。运行会话默认两分钟、同一服务最多一个。没有一般代码执行能力或严格内存配额保证；所列有限探针不等于对浏览器任意漏洞的证明。

macOS 27.0.1 上曾尝试用 sandbox-exec 外层规则限制网络，即使外层 allow-default，嵌套后的浏览器目标页仍崩溃。没有为通过实验关闭 Chromium 自身沙箱；采用当前受管进程方案，记录该失败与边界。网络阻止依据实际代理、请求与 CSP 检查，不声称已实现内核网络隔离。

复用组件是实际受控 HTML/CSS/JS，数组最多 32 个受限升序整数。新代码先保存候选，执行服务器固定的行为检查，提交候选只登记 prepared_candidate；正式资源仍由任务提交资格、版本依赖、候选归属、文件 SHA 和独立检查决定。

真实供应商资源对照、真实工具失败反馈修复与进程恢复已执行，有限结果见 M5 报告；独立教学人审未知。开发脚本策略始终标记为 deterministic_resource_fixture，不包装成实际模型 Agent 的质量证据。
