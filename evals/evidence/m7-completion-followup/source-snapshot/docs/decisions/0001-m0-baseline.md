# M0 技术与产品基线

日期：2026-10-07。适用范围：M0 契约实验，以及 M1 初始化的起点。真实模型由用户指定为 DeepSeek V4.1 Flash，本轮总预算不超过人民币 5 元。精确 API 名为 `deepseek-flash`，属于供应商可更新的别名，不能承诺锁定权重快照。

## 技术选择

| 部分 | 锁定选择 | 理由与替代方案 |
| --- | --- | --- |
| 后端 | CPython 3.12.14 + FastAPI 0.142.2 | Python 集中处理生成与领域校验；FastAPI 适合异步 HTTP。TypeScript 服务端可减少语言数量，但当前优先后端与 AI 工程主线。 |
| 契约 | Pydantic 2.12.5 + JSON Schema 2020-12；jsonschema 4.25.1 | Pydantic 执行严格类型和领域规则；独立 JSON Schema 校验区分结构与业务合法。保留成熟维护版本，不以追逐最新版本为目标。 |
| 模型 | DeepSeek V4.1 Flash，HTTP Responses API，httpx 0.28.1 | 用户选定供应商；薄适配层无需完整 SDK 或编排框架。使用非思考模式、temperature=0.2，服务端校验，不假定供应商强制遵守 schema。 |
| 数据库 | PostgreSQL 18；SQLAlchemy 2.0.54 + Alembic 1.20.0 + psycopg 3.3.6 | M1 起使用真实数据库验证事务和并发。SQLite 不用于替代并发验收；SQLAlchemy 使用已维护的 2.0 分支，暂不迁移 2.1。数据库镜像 patch/digest 在 M1 启动前锁定，当前未安装/运行。 |
| 前端 | React/React DOM 19.3.0 + TypeScript 7.0.2 + Vite 8.3.3 | 无 SSR 需求，以工作区交互为主。Node 26.10.0 是本机已验证运行版本；前端工程与包锁在 M1 创建。 |
| 布局 | `src/unfold`、`tests`、`contracts`、`evals`，M1 增加 `web` | 一个仓库与模块化单体；契约/实验代码直接复用。暂不引入微服务、Redis、队列服务、向量库或 LangGraph。 |
| 运行 | 本地单用户，服务绑定 `127.0.0.1`；受管文件目录 | 先可重复本地运行，再决定私有服务器。远程访问、账户与公共服务在对应阶段验收，M0 不建立部署资源。 |
| 工具 | uv 0.12.23；pytest 8.4.2、Ruff 0.13.2、mypy 1.18.2 | M0 使用精确依赖和 `uv.lock`，普通检查完全离线。前端、数据库与浏览器测试从实际功能引入时运行。 |

Python 是实际本地执行版本。M0 使用的 Python 包及其传递依赖已锁定并安装验证。FastAPI/数据库与前端版本于开工时查询官方包索引确定，目前属于 M1 指定起点，其集成兼容性仍需 M1 检查；不将版本查询记为应用启动成功。网页展示、图片、Mermaid、KaTeX 等 M4/M5 库在接入时锁定，不提前安装未使用依赖。

模型元信息经认证的 `/models` 查询确认；官方 [模型说明与价目表](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/) 和 [Responses 契约](https://api-docs.deepseek.com/api/create-response/) 为接入参考。实际兼容性结论以本项目的运行记录为准。

## 初始产品参数

- 用途问答累计最多 5 题、最多 2 轮；每轮同一用途维度最多一题，已明确的维度不再询问。单选/多选同时允许自由补充与明确未知。信息足够时可以零题，追問预算结束使用显式假设开始，不能伪造用户答案。
- 初次只生成根与第一层，每层最多 8 个子项。数量上限是执行预算，不能作为叶子理由。范围足够小可直接根叶子；层数不是普遍质量目标。
- 默认练习 3 题，单次 1～5 题；单选答案唯一，多选按稳定选项 ID 集合完全相等判分，无部分得分。不在普通题目响应中发送答案与解析；真实答题接口在 M4 实现。
- 浏览复用已保存内容；已有展开再次点击只读结果。主动重生成是独立请求、新幂等键和新修订；替换已有结构先给出预览，保留旧版本与用户修改，首版不自动合并、删除或移动已有节点。
- 有效叶子禁止普通展开及结构重生成。补充讲解和练习不改变判定。目标变更或终点反馈使用独立 `reassessment`；过期判定先重评，不默认开放。
- 重评将已有子树的节点改为叶子时，只提出待审核的结构建议，不能同时保留矛盾的活动子树或直接删孩子。
- 模型候选不含服务端发布状态、实际下载 URL、执行成功、文件地址、用量或新增正式 ID；局部 key 经应用校验后绑定。资源制作单独执行，正文不等待媒体。

## 实验边界

真实实验与手写契约样例分开。每次模型阶段最多一次修复，不自动重试超时、拒答、认证错误或未知结果，不静默降级为正文解析。每批最大 48 次调用、单次输出 4,000 token、请求 48,000 UTF-8 字节、单次 HTTP 超时 60 秒、批次墙钟 1,200 秒、并发 1。初始核心场景每个 3 次独立试验；额外跨用途/领域冒烟在调用前固定选择与次数。

费用预留按官方高峰价格、全部输入视为缓存未命中：输入 2 元/百万 token，输出 8 元/百万 token。请求以字节量加协议余量预留输入，再按返回用量结算；用量未知保留全额预留，不能计零。跨批次扣除已有调用的保守费用，累计不能超过用户授权 5 元。预估不是账单，供应商实际余额差及其归因限制在报告中单列。供应商价格变化时必须重查，不能继续使用旧价格声称满足费用上限。

保留集尚不用于调提示或确定阈值；从开发基线确定接受标准后冻结评价文件。人工评分以 0/1/2 检查用途、增量、结构、停止与内容对齐；事实待核验另列。Codex 的审阅不冒充独立人工评分，不用 schema 合法率声称知识准确率。
