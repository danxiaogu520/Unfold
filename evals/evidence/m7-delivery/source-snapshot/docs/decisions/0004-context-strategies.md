# 0004：保留当前路径默认值，提供显式上下文对照

日期：2026-10-07。状态：采用。详细样本与数字以 [M6 报告](../reports/m6-context-2026-10-07.md) 为准。

同一学习操作可以选择 current_path、structural_relevance 或 all_history。默认使用当前路径；非默认策略参与活动任务身份，避免复用输入材料不同的任务。历史默认请求幂等摘要保持兼容。

必需材料是完整任务输入、当前设定、范围、路径和已有子项。输入材料预算 24,000 UTF-8 字节，预留 4,000 输出 token；这是一项应用预算，不宣称等于供应商上下文窗口。必需材料装不下就明确拒绝；全历史不改成静默截断策略。

结构策略使用保存关系和中英文关键词排序，不使用向量检索。旁支正文采用最多 600 字符的程序摘录，注明原文、选入与省略字符数、来源状态和依赖 SHA。它没有经过新的模型推理，也不被标为已核验事实。内容、设定、结构、路径或问题标记改变后重建。

M6 对照只发送本轮新建的公开合成数据。每个候选使用真实持久调用和费用结算，但在发布前主动取消，保持每个策略面对同一正式快照；该结果只能说明候选契约与输入成本，不能写成正式学习任务发布成功率。应用正常发布与竞争资格另由数据库/HTTP/浏览器测试验证。

新策略尚无经独立人工校准的质量收益证据，额外输入也有费用。因此保留当前路径默认值，结构选择用于明确的关联需求，全历史用于容得下预算的小空间。暂不引入向量、重排或复杂模型摘要；若要改变默认值，先固定下一版数据与质量口径。
