## 执行与工具

网页在独立临时 Chromium 进程执行，保留浏览器自身沙箱，来源为 opaque null，无主应用窗口、Cookie、localStorage 或 Node API。模型凭据和后端配置从驱动环境移除。主应用只接收 PNG 画面、经校验的坐标、有限按键和文本；两分钟会话、最多一个运行，支持停止和重置，关闭页面不会再次推理。

网络叠加 CSP、请求拦截、拒绝代理、禁用非代理 WebRTC UDP 和静态能力拒绝。操作墙钟超时会终止该进程组。宏观内存配额、一般服务端沙箱与任意浏览器漏洞安全证明不在本次已验证范围；没有声称 iframe 可以保证 CPU/RAM 配额。macOS sandbox-exec 与 Chromium 自身沙箱嵌套导致目标页崩溃，未通过关闭浏览器沙箱规避。详见 [执行边界](../decisions/0003-managed-resource-browser.md)。

九种工具：实际资源查询、当前内容读取、受控组件制作、网页写入、当前候选读取、独立浏览器检查、候选提交、Commons 检索和已提供图片引用获取。参数均单独校验；不可读取其他任务文件/候选、改变检查规则或通过模型返回地址声明资源就绪。文件按 SHA 保存，模型提交只写 prepared_candidate；应用最后检查 lease/attempt、内容依赖、归属、文件摘要与独立检查。

逻辑 AgentStep 按 run 保存，与 worker attempt 分开；决策、工具开始、完成/失败和观察可追踪。已完成步骤原样复用；写入后结果未保存时凭逻辑 step、输入摘要和实际候选恢复，读取/浏览器检查可按声明的幂等行为重复。未知窗口单列，不盲目承诺外部调用严格一次。

每个资源默认至多八个步骤、八次供应商调用、150 秒首次执行起的总墙钟预算，恢复不重置计时。每次调用继续经过持久费用预留和取消检查；正式发布永远由当前执行资格决定。Python、真实数据库读取、包导入、外部资源、worker 和明显无界循环不提供。

## 真实对照

固定三个 M0 开发任务：search_component-1（实际组件复用）、function_plot-1（从有错误的同一初始网页修复）、python_database-1（能力外退出）。三流程使用相同工具、运行环境和独立行为规则；单次流程仅有一次生产决策，固定修复至多再一次，Agent 每次选择下一工具。随机顺序在调用前保存，保留集未用于调提示。

全部资料为新建、标明来源的公开合成评测，不读取既有私人学习空间。每次决策保存实际输入/输出、用量、耗时与工具观察。函数规则检查四组 k,b,x、重置及真实图像变化；二分检查命中、未命中、空数组、ArrowRight 单步及重置。小样本不是领域正确性或学习效果证明。
