# GitHub 开源整理

日期：2026-10-07。目标仓库为 danxiaogu520/Unfold，原创源码与文档采用 MIT；第三方图片的 CC0 许可、作者和来源另列。首版支持本地单用户，源码公开不扩大应用的运行边界。

## 文件范围

公开范围包括 src、web 的源文件与锁文件、contracts、scripts、tests、产品/技术/开发文档、GitHub CI，以及经过审查的合成评测证据。README 改为产品介绍、安装入口、实际限制与证据索引，避免将个人预算配置写成新使用者的运行条件。

私密 .env、实际学习数据库、备份、模型运行原始目录、安装后的依赖、本地工具、缓存和生成报告保留在本机，均不进入 Git。证据清单引用的 .log 是公开结果的必要组成部分，使用显式忽略例外纳入；一般运行日志仍忽略。

## 脱敏与证据连续性

历史公开候选文件中出现的本机工作区和用户目录，分别替换为 `<workspace>` 和 `<local-home>`。这些变更只涉及路径表示，不改变实验结果、失败、模型内容、费用、用量或时间。

原件在忽略的本地私有目录另行保存。`evals/evidence/publication-redactions.json` 记录每份副本的脱敏前后 SHA-256、替换次数及受影响的清单；对应 manifest 的哈希更新为公开副本，并加注 public_export。后续校验确认公开副本的完整性，不宣称其字节仍与未脱敏原件相同。未受影响的冻结来源快照和模型输出保持原样。

## 发布检查

`scripts/audit_publication.py` 扫描 Git 选择的文件，检查私密/生成路径、配置中的实际密钥、常见凭据模式、本机用户路径、符号链接、文件大小和证据引用完整性。`--staged` 还核对暂存 blob 与已扫描字节，防止暂存旧版本绕过检查。错误只输出文件名与类别，不输出命中的密钥。

统一检查与 GitHub CI 都运行此扫描；检测范围不等于可以证明不存在所有形式的机密信息。发布前另外检查 Git 暂存清单与冻结证据的哈希。全部验证使用固定替身，不增加真实模型费用。

本地完整验收通过：18 项统一检查、213 项 Python 测试（真实 PostgreSQL，0 跳过）、10 项 Chromium 流程。新的离线清洁安装通过空 schema 迁移、实际 HTTP/worker、自动大纲、三题保存与判分；没有复制旧虚拟环境、node_modules 或模型凭据，也没有新增真实模型调用。

扫描的对抗检查确认：公开正常暂存通过，模拟密钥被拦截且不回显，强行暂存的私密 .env 被拦截，暂存与工作区不一致被拦截，漏入 Git 的证据日志被拦截。本机路径脱敏涉及25份文件和6份清单，全部31份公开哈希复核一致。移除运行产生的测试/格式/类型缓存、Python 字节码和前端生成目录，保留本地数据库、配置、备份与已安装依赖。

发布提交见 [GitHub 仓库](https://github.com/danxiaogu520/Unfold)，远程验收状态见 [GitHub Actions](https://github.com/danxiaogu520/Unfold/actions/workflows/ci.yml)。远程结果以对应提交的运行记录为准。历史里程碑报告的“没有 Git 提交/远程 CI”表示它们各自冻结时的事实。

## 首次远程失败与收尾修订

[首次远程运行](https://github.com/danxiaogu520/Unfold/actions/runs/37639880909) 在 Ubuntu 24.04 上有7项 Python 测试失败、206项通过，原因是受管 Chromium 沙箱无法启动。按 Ubuntu 官方的应用专用 profile 方式，为临时运行器的 Playwright Chromium 允许 userns；不关闭 Chromium 沙箱，也不关闭整台运行器的 AppArmor 用户命名空间限制。后续远程运行以 GitHub 对应提交结果为准，首次失败保持可查。

Python 源码包初次本地复核发现，全局示例 .env 忽略例外会使构建后端误带本地生成目录中的示例配置。这些产物未上传。修订将示例文件例外限定为根目录与公开证据，并为 sdist 设置顶层文件白名单；源码包和 wheel 另行复核目录、实际密钥匹配与 MIT 许可文件。Git 推送始终只包含已通过暂存扫描的文件，实时配置、数据库和备份从未提交。
